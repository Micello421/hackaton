# Hackaton — instrukcje dla agenta

To repo jest projektem na **hakaton**. Pracujesz lokalnie na PC właściciela; wynik musi trafić na GitHub.

## Zawsze na koniec taska
1. Zrób sensowny commit (lub kilka logicznych).
2. Wypchnij branch na `origin`.
3. Otwórz / zaktualizuj **Pull Request** do `main`.
4. W odpowiedzi podaj:
   - link do PR
   - nazwę brancha
   - jak uruchomić projekt lokalnie (komendy)
   - co przetestowałeś i wynik

## Reguły
- Nie commituj sekretów (`.env`, klucze, tokeny).
- Preferuj małe, działające MVP zamiast wielkiej architektury.
- Po zmianach odpal build/test jeśli istnieją; jeśli fail — napraw.
- README aktualizuj, gdy zmienia się sposób uruchomienia.
